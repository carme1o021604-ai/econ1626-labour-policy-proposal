# ECON1626 Labour Policy Proposal

## Project Overview

This repository contains my ECON1626 Assessment 2 policy proposal. The proposal examines how artificial intelligence, especially generative AI, is changing the labour market through task automation, task augmentation, changes in wages, workforce restructuring and new skill requirements.

The proposal is addressed to a named policy client and develops concrete policy options for helping workers adapt to AI-related labour market change.

## Repository Structure

1. Open `README.md` for the project overview.
2. Open `proposal.md` to read the full policy proposal.
3. Review the commit history to see how the proposal was developed over time.

## Proposal Structure

The proposal includes:

- Title and executive summary
- Problem definition and context
- Analysis of AI impacts on employment, tasks, wages and industry structure
- Policy options and evaluation
- Recommended package and implementation plan
- Risks and mitigations
- References

## Technical Notes

The proposal is written in Markdown so that headings, lists, tables, links and references render correctly on GitHub.
